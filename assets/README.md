# Static Assets

This directory contains production assets used by the public website.

- `css/main.css`: shared visual styles
- `js/main.js`: language switching, navigation, and publication filtering
- `images/brand/`: favicon and brand assets
- `images/profile/`: public portrait images
- `images/research/`: research frameworks and system diagrams
- `images/venture/`: industry and venture materials

Use lowercase English filenames with hyphens. Keep only assets referenced by the
website; Git history serves as the archive for replaced or removed files.
